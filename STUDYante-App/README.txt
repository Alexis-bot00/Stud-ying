STUDYante App - First Working Build

This build includes:
- Red and blue STUDYante design
- Home dashboard and progress
- Working task creation and completion
- Editable quick notes
- Student profile
- Bottom navigation

HOW TO ADD IT TO YOUR EXPO PROJECT

1. Stop Expo by pressing Ctrl+C in PowerShell.
2. Extract this ZIP file.
3. Copy the extracted "app" folder.
4. Paste it inside your existing STUDYante-App folder.
5. Choose "Replace the files in the destination" if Windows asks.

Then run these commands in PowerShell:

cd "C:\Users\Alexis Dustin\Desktop\Alexis data\MyPortfolio\Sudying\STUDYante-App"
npm.cmd run web

Note: Tasks and notes work while the app is open. Permanent saving and login/database features can be added in the next version.
